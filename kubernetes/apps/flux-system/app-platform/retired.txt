# Platform apps that were retired on purpose, one name per line.
#
# Deleting an entry file orphans the app (the workload keeps running without
# updates), and a renamed entry is a delete plus an add: the old app is left
# behind and a new, empty one starts. So on a pull request scripts/validate-apps.sh
# fails when an entry file that exists on the base branch is gone, unless its
# name is listed here. Add the name in the same PR that deletes the entry, after
# deciding what happens to the workload, its PVC and its backups (see
# kubernetes/apps/personal-apps/README.md, "Retire an app"). A listed name must not
# have an entry file; keep the line afterwards as the record.
